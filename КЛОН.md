# Клонирование и запуск HEFEST

Два способа получить рабочую систему из репозитория.

## Что лежит в репо, а что нет
- **В репо:** код, UI, документация, данные-источники (`data/*_clean.json`, `physchem.json`, `.docx`),
  и **векторный индекс `data/embeddings_clean.npy` через Git LFS** (~106 МБ).
- **Не в репо** (пересоздаётся): локальный индекс Qdrant, бэкап-`*.npy`, кэши, `.env`, рантайм-логи.

## Способ A — с LFS (под ключ, без пересборки)

Нужен установленный [Git LFS](https://git-lfs.com).

```bash
git lfs install
git clone git@github.com:ilyautov/hefest.git
cd hefest
git lfs pull          # дотянет embeddings_clean.npy (если не пришёл при clone)
```

Эмбеддинги уже на месте — можно сразу запускать семантический режим (см. ниже).

## Способ B — пересобрать индекс из корпуса (без LFS)

Если LFS не нужен/недоступен — эмбеддинги восстанавливаются из корпуса локально.
Нужна [Ollama](https://ollama.com) с моделью `bge-m3`.

```bash
git clone git@github.com:ilyautov/hefest.git
cd hefest
bash rebuild_index.sh   # 26k чанков через Ollama bge-m3 -> data/embeddings_clean.npy (с чекпойнтом)
```

## Запуск сервиса

**Лексический режим** (быстро, без Ollama — работает даже без эмбеддингов):
```bash
SUBS_FILE=substances_clean.json CORPUS_FILE=corpus_full_clean.json \
LLM_BACKEND=extractive \
python3 -m uvicorn service:app --app-dir engine --port 8012
```

**Семантический режим** (нужны эмбеддинги из A или B + Ollama с `bge-m3` и `qwen2.5:7b`):
```bash
SUBS_FILE=substances_clean.json CORPUS_FILE=corpus_full_clean.json \
RETRIEVER=semantic EMB_FILE=embeddings_clean.npy IDS_FILE=embed_ids_clean.json \
LLM_BACKEND=ollama OLLAMA_LLM=qwen2.5:7b \
python3 -m uvicorn service:app --app-dir engine --port 8012
```

Открыть: http://127.0.0.1:8012/ · здоровье: `/health`.

> Подробное развёртывание (в т.ч. КИИ-контур, Docker) — `setup.sh`, `DEPLOY.md`, `docker-compose.yml`.
