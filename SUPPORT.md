# Поддержка

По установке, настройке и использованию — открывайте GitHub Discussion или issue по
подходящему шаблону. Приложите:

- операционную систему и версию Python (`python3 --version`);
- режим запуска (лексический / семантический) и переменные окружения без секретов;
- вывод `GET /health` и `GET /quality`;
- воспроизводимую команду или запрос.

Если считаете, что система выдала неверное нормативное значение, — это шаблон **«Спор о
нормативном значении»**, а не обычный баг: там сразу спрашивают источник и способ
воспроизведения.

**Не публикуйте** паспорта безопасности предприятия, реестры площадок, аудит-логи и ключи.
Если для воспроизведения нужен фрагмент данных — приведите минимальный обезличенный пример.

Уязвимости и подозрения на утечку данных **не публикуются** в issue — см. [SECURITY.md](SECURITY.md).

Проект в раннем доступе; поддержка оказывается по мере возможности, без обязательств по
срокам ответа.
