# Данные: происхождение, права, условия использования

Лицензия MIT (`LICENSE`) распространяется на **код**. Данные в `data/` имеют разное
происхождение, и относиться к ним нужно по-разному. Эта страница отвечает на три вопроса:
откуда значение, можно ли его распространять, и что с ним нельзя делать.

Сквозной принцип проекта: **значение без провенанса не хранится**. У каждой записи есть
`source_tier` (уровень источника) и `confidence` (уровень доверия), у каждого чанка корпуса —
цитата с указанием вещества и раздела.

---

## 1. Нормативные значения РФ (ПДК, класс опасности)

**Что:** предельно допустимые концентрации рабочей зоны, атмосферного воздуха и воды,
классы опасности по степени воздействия на организм.

**Источники:** ГН 2.2.5.3532-18, СанПиН 1.2.3685-21, ГОСТ 12.1.007-76. Реестр применяемых
актов со статусом и версией — в `engine/normative.py`, дашборд — `GET /normative`.

**Права:** официальные документы государственных органов, их официальные переводы и
подобные материалы **не являются объектами авторского права** (ГК РФ, ст. 1259, п. 6).
Числовые значения нормативов — факты, а не творческий результат. Извлечение и
распространение допустимы.

**Ограничение по применению:** нормативы **меняются**. Значения в репозитории соответствуют
редакции на дату сборки данных, а не на дату вашего использования. Перед производственным
применением сверьте с действующей редакцией — это шаг приёмки, а не формальность.

**Исходные файлы** нормативных документов (`data/sources/*.docx`) в репозиторий **не
включены**: они объёмны и общедоступны у первоисточника. Скрипты ингеста
(`engine/ingest_sanpin.py`, `engine/ingest_sanpin_env.py`) принимают их путём аргумента —
см. `GROW-BASE.md`.

## 3. Сгенерированная форма паспорта

**Что:** тексты 16 разделов по структуре ГОСТ 30333-2022 в `corpus_full_clean.json`.

**Как получено:** программно собрано из структурных карточек веществ модулем
`engine/corpus.py`. Метаданные корпуса прямо это фиксируют:
`"nature": "реальные регуляторные данные (ГН 2.2.5/СанПиН), документ-форма сгенерирована"`.

**Права:** оригинальная работа проекта, распространяется на условиях MIT.

**Ограничение:** это **не оцифрованные паспорта реального предприятия**. Главная трудность
внедрения — грязные сканы, OCR, таблицы — на этих данных не проявляется. См. `LIMITATIONS.md`.

## 4. Реестр предприятий (`plants.json`)

**Что:** 13 химических предприятий, их ИНН, ОКВЭД, публичные продуктовые линейки и связь
«предприятие ↔ вещество».

**Как получено:** из открытых источников — ЕГРЮЛ (ИНН, ОКВЭД) и **публичных каталогов
продукции самих предприятий** (сайты компаний). Публикация сведений из ЕГРЮЛ допустима:
реестр открыт по 129-ФЗ.

**Что этот набор НЕ означает — читайте внимательно:**

> Связь «предприятие ↔ вещество» выведена из **публично заявленной продукции**, а не из
> инвентаризации опасных веществ предприятия, не из деклараций промышленной безопасности и
> не из сведений, полученных от самих организаций. Это **демонстрационная модель связей**
> для показа работы поиска по площадке. Она не описывает фактическое обращение опасных
> веществ на конкретной площадке, их объёмы и условия хранения, и не должна использоваться
> для выводов о состоянии промышленной безопасности названных организаций.

Если вы разворачиваете систему у себя — замените этот файл собственным реестром. Для
публичной демонстрации без привязки к реальным юрлицам используйте обезличенный вариант:

```bash
python3 engine/anonymize_plants.py          # → data/plants_demo.json
PLANTS_FILE=plants_linked_demo.json python3 -m uvicorn service:app --app-dir engine --port 8012
```

**Обращение правообладателя или упомянутой организации:** если вы представляете одну из
названных организаций и считаете, что запись некорректна или нежелательна, откройте issue с
префиксом `takedown:` — запись будет исправлена или удалена. Это канал по содержанию;
уязвимости контура честности идут приватно (см. `SECURITY.md`).

## 5. Векторные эмбеддинги

`data/embeddings_clean.npy` (~106 МБ, Git LFS) — векторы, посчитанные моделью **bge-m3**
(лицензия MIT) по сгенерированному корпусу. Производный артефакт: пересобирается из корпуса
командой `bash rebuild_index.sh`. Клонировать репозиторий без LFS — рабочий сценарий.

## 6. Что делать при сомнении

Если вы не уверены в происхождении конкретного значения:

1. `GET /substance/{имя}` — карточка с `source_tier`, `confidence` и статусом верификации;
2. `GET /quality` — сводка честности по всей базе, включая целостность CAS;
3. `GET /normative` — какие акты и в какой редакции применяются;
4. если значение выглядит неверным — откройте issue по шаблону
   **«Спор о нормативном значении»**: он требует источник и воспроизводимую команду.
