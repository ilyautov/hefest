# Питч-контекст (внутренний)

Вынесено из публичного `README.md` при подготовке репозитория к открытой публикации: это
коммерческая рамка проекта, а не документация продукта. Читателю из GitHub она не нужна и
сбивает фокус; автору — нужна.

## Честная рамка

Проект — **capability-proof**: «умеем собрать индустриальную систему на реальных данных, она
работает, метрики честные, on-prem». Это **не** доказательство экономии у конкретного завода.
На приватной грязной базе предприятия числа надо переснимать. В питче не смешивать.

## Связь с предложением ТПП

- **Ступень 0 (семинар):** сгенерированный офлайн-UI как живое демо на реальных заводах города.
- **Ступень 1 (аудит-спринт):** тот же конвейер на реальных паспортах одного завода. Грабля
  грязных данных — то, за что платят.
- **Финансовый рычаг:** GigaChat-бэкенд под субсидию РФРИТ 50%.
- **Отстройка:** вендор-нейтральность, on-prem MCP-граница, связка «завод ↔ вещество»,
  адаптированная под средний бизнес.

Для публичного показа реестр площадок обезличивается — `make demo`, см. `DATA-LICENSE.md`,
раздел 4.

Рыночная часть — `MARKET.md`, сценарии показа — `DEMO.md` и `docs/ДЕМО-СЦЕНАРИЙ.md`.
